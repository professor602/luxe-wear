# LuxeWear – Fashion Store

A responsive e-commerce fashion store frontend built with **HTML5, CSS3 and Vanilla JavaScript**.
Created as a Web Engineering course assignment.

**Live demo:** https://professor602.github.io/luxe-wear/

## Features
- 15 pages: home, shop, men, women, kids, product details, cart, wishlist, login, sign up, profile, checkout, order confirmation, about, contact
- Search, filters and sorting
- Cart and wishlist saved in LocalStorage
- Demo login/registration, profile editing and order history
- Form validation, toasts, scroll animations, responsive layout
- Supports `prefers-reduced-motion`

## Run locally
1. Clone the repository
2. Open the folder in VS Code
3. Right-click `index.html` → **Open with Live Server**

## Important notice
This is an **academic demo**. Login uses LocalStorage, so passwords are **not secure**.
Do not enter real passwords, payment details or personal information.
Real authentication requires a secure backend.

## Project structure
- `assets/css/` styles, responsive rules and animations
- `assets/js/` product data, storage helpers, shared UI and page scripts
